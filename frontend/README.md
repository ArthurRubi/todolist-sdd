# Frontend

Cliente web da aplicação TodoList.

## Estado

Ainda não inicializado. O scaffold só será criado por uma tarefa derivada de uma especificação aprovada.

## Linha de base proposta

- React com TypeScript.
- Vite como ferramenta de desenvolvimento e build.
- Integração com a API por contrato OpenAPI.
- Testes de unidade e componentes com Vitest e Testing Library.
- Testes E2E quando exigidos pela especificação ou pelo plano.

## Limites do módulo

O frontend é responsável por apresentação, interação, acessibilidade e estado de interface. Regras de negócio que precisam ser confiáveis não devem existir apenas no navegador.

Quando o módulo for criado, este README deve documentar estrutura real, pré-requisitos, comandos de desenvolvimento, testes, build e variáveis de ambiente — sem duplicar a especificação da funcionalidade.
